# 夏哥视频封面 · Xiage Video Cover

[English](README.en.md) · [技能指令](SKILL.md)

把视频脚本和本人照片，变成主题鲜明、标题醒目、多比例适配的视频封面。

这是夏哥研究室在实际封面制作中整理出的 **Codex 工作流技能**：AI 负责读脚本、提炼标题、设计画面并调用图像生成工具；创作者提供素材和审美反馈。它不是独立运行的软件，也不包含图像生成模型或视频剪辑功能。

![口播包装 Skill 封面](examples/skill-launch-16x9.png)

## 能做什么

- 从完整脚本里提炼一个核心卖点，写成主标题和副标题。
- 以本人照片为人物参考，保持真实五官、发型和自然体态。
- 根据每期内容设计视觉主题，不机械套用同一种配色或布局。
- 先制作主版，再按反馈迭代，并为横竖版分别重新构图。
- 检查文字、人物、遮挡、缩略图可读性和实际像素比例。

| 比例（宽:高） | 用途 | 建议尺寸 |
| --- | --- | --- |
| 3:4 | 竖版主封面 | 1080×1440 |
| 16:9 | 宽屏横版 | 1600×900 |
| 4:3 | 紧凑横版 | 1440×1080 |

建议尺寸不是强制输出分辨率，其他精确同比例尺寸也可；交付时核对实际文件。

## 使用条件与安装

需要支持本地技能的 Codex 环境，以及可用的 `imagegen` 技能和内置图像生成工具。本仓库只提供工作流，不自动安装这些能力。图像生成的可用性、用量和耗时取决于你的运行环境。默认路径不需要用户另行提供 API Key；若改用 API，需要按所选工具另行配置。

下载本仓库后，让 Codex 安装：

```text
请把这个仓库中的 SKILL.md 安装为个人技能 xiage-video-cover。
保留已有同名技能，先比较内容再更新。
```

也可以把 `SKILL.md` 放到当前 Codex 使用的个人技能目录下的 `xiage-video-cover/` 文件夹。作者环境使用 `~/.codex/skills/xiage-video-cover/SKILL.md`；不同环境请按其技能目录配置。不要覆盖已有自定义内容。安装后在可用技能列表确认，必要时新开任务。

## 快速开始

附上脚本和人物照片，然后发送：

```text
用 $xiage-video-cover 帮我做这期视频封面。

脚本：[粘贴脚本]
人物照片：[附图]
署名：夏哥研究室
特别要求：[没有就自由发挥]

你来提炼标题和视觉主题。先做 3:4 主版，
我认可后再适配 16:9、4:3 横版。
```

其他创作者可以把署名换成自己的名称；技能中的默认品牌是「夏哥研究室」，当次明确要求优先。封面文字语言、人物位置和视觉配色也可在请求中指定。

## 工作流

1. **提供素材**：脚本或摘要、本人照片；参考封面和真实软件截图可选。
2. **提炼主题**：选择整期的主要成果或观众价值，不必把开场铺垫作为封面主题。
3. **设计主版**：生成 3:4 封面，明确标题层级、主题色、人物和背景元素。
4. **反馈修订**：例如“人物更大”“背景简单点”“标题改成这句”。
5. **适配比例**：主版认可后完成两个横版；用户要求直接整套制作时可连续完成。
6. **检查交付**：保存成品、实际尺寸和生成提示词，提供文件链接。

技能保存的是方法和偏好，不会自动携带旧照片。新对话请重新附图，或指定仍可访问的素材位置。

## 边界与检查

- 图像生成可能出现文字错误、人物偏差或手部异常，需要查看成图并迭代，不能保证一次成功。
- 不把多步骤流程写成“一键完成”，不新增无依据的耗时、收益或零返工承诺。
- 要准确展示产品，请提供真实截图；生成的界面不能当作产品实拍。
- 多比例适配以重新构图为主，不能拉伸人物或裁掉标题。
- 本仓库包含成品示例，不包含原始人物照片、个人机器路径或账号凭据。
